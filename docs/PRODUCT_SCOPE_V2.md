# Radar Salud V2 — Product Scope

## Product thesis
Radar Salud observes large volumes of public market information, structures each event as a Signal, connects related Signals, detects emerging patterns and makes the health market queryable.

Core services are deliberately limited to six verbs:

1. **DISCOVER** — what happened.
2. **WATCH** — what I must not miss.
3. **CONNECT** — which apparently separate events are related.
4. **TREND** — which pattern is emerging, accelerating, established or cooling.
5. **BENCHMARK** — how visible activity compares across actors/groups using public evidence.
6. **ASK** — query the accumulated market knowledge with traceable sources.

## Core
- DISCOVER
- WATCH
- CONNECT / Signal Connections
- TREND
- BENCHMARK
- ASK
- Web knowledge base
- Daily Pro digest / Weekly Free digest
- Watch alerts as the only intraday push exception
- Personal relevance by user profile
- Spanish presentation of non-Spanish sources, preserving original link
- Legal / regulatory monitoring as high-value source families

## Nice to have
- LinkedIn automated editorial output based on public TREND insights
- One-off premium deep dives based on Radar evidence (not a report-builder product)
- Radar Mundo as a small curated layer, not a global news feed
- Talent/jobs as both user value and strategic market signal
- Startup/innovation intelligence
- Regional / cross-country comparisons

## Explicitly out of scope / discarded
- Private-file ANALYZE as a core feature
- Generic AI assistant capabilities
- Generic report/PPT generator
- Waze/community crowdsourcing
- Courses
- Consulting as the core model
- Marketplace

## Signal hierarchy
1. **Signal** — one factual event.
2. **Connected Signal** — relationship between two or more Signals.
3. **Trend** — repeated multi-event/multi-entity pattern.
4. **Strategic Theme** — persistent Trend over a longer horizon.
5. **Prospective Signal** — evidence cluster consistent with a possible future move; always expressed probabilistically and never as an unsupported prediction.
