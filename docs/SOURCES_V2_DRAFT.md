# Source universe V2 — draft for tomorrow's review

## MVP candidates (Chile)
### Tier A — proposed day-one / first 60 days
- Superintendencia de Salud: regulations, statistics, portfolio, mobility, FEFI, publications.
- MINSAL: institutional news, infrastructure, policy, COMPIN-related public publications.
- SUSESO: regulation, rulings/circulars, occupational-health statistics, mutual-system information.
- Mercado Público / ChileCompra: public tenders and procurement; official API/open-data routes.
- Diario Financiero: high-trust Chilean corporate/market signal discovery.
- Reuters: one international source for Radar Mundo, user-facing text translated to Spanish.

### Tier B — high-value additions after base pipeline is stable
- Poder Judicial: relevant public judicial developments / Legal Watch.
- BCN / LeyChile.
- Diario Oficial.
- FONASA.
- DEIS.
- INE.
- CASEN / Observatorio Social.
- CEP.
- CMF for relevant corporate/financial disclosures.
- ISP.
- Direct corporate newsrooms/career pages for major health actors.

### Innovation / startup candidates
- Start-Up Chile.
- LAVCA.
- LatamList.
- Dealroom public ecosystem/profile data, subject to permitted access.
- Corporate accelerator / VC portfolio announcements where useful.

### Talent intelligence candidates
- Direct corporate career pages / public ATS feeds.
- Publicly available recruitment pages that permit automated access.
- LinkedIn as a distribution/discovery complement only; do not make MVP dependent on scraping it.

## Final-product source families
- Official regulators and ministries
- Courts / legal sources
- Procurement
- Company disclosures
- High-trust financial/business media
- National statistics / surveys
- Provider/insurer/mutual corporate sites
- Careers / talent
- Startup / VC / innovation ecosystem
- Academic / research institutions
- One or more trusted international health/business feeds per region

## Source principle
Every source has structured metadata: country, source type, trust, cadence, access method, permitted usage, target domains and MVP status. The system should prefer primary sources when available, without automatically penalizing high-trust journalism merely because corroboration is absent.
